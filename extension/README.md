# X 키워드 가리개

X(트위터)에서 지정한 키워드나 계정이 들어간 게시물·답글·인용·알림·트렌드를 가려주는 크롬 확장입니다.
크롬, 엣지, 웨일 등 크로미움 브라우저(PC)에서 동작합니다.

## 설치

1. zip 압축을 풉니다.
2. 주소창에 `chrome://extensions` 입력 (엣지는 `edge://extensions`, 웨일은 `whale://extensions`)
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 `x-keyword-hider` 폴더 선택
5. 퍼즐 아이콘에서 고정(핀)해 두면 편합니다.

## 쓰는 법

- 아이콘을 눌러 키워드를 한 줄에 하나씩 적으면 바로 적용됩니다 (자동 저장).
- `@아이디` → 그 계정이 쓴 글, 재게시, 그 계정이 언급된 글
- `#해시태그`, 이모지도 됩니다.
- `/정규식/i` → 정규식 (예: `/코인\s*무료/i`)
- `//`로 시작하는 줄은 메모로 무시됩니다.
- X에서 글자를 드래그하고 우클릭 → "가리기 키워드에 추가"
- 프로필·게시물 링크를 우클릭 → "이 링크의 계정 가리기"

## 동작 방식

- 영어 키워드는 단어 단위로 맞춥니다 (`ai`가 `said`에 걸리지 않음). 한글은 조사가 붙어도 잡습니다 (`분탕이`, `분탕을`).
- "띄어쓰기·기호 끼워넣어도 잡기"를 켜면 `분 탕`, `분.탕` 같은 우회도 잡습니다.
- 접어두기 모드에서는 걸린 글 자리에 빨간 **BLOCKED**(Bebas Neue)만 남고, 그 자리를 누르면 그 글만 펼쳐집니다.
- "BLOCKED 아래에 걸린 키워드 표시"를 켜면 어떤 키워드에 걸렸는지 BLOCKED 밑에 작게 보여줍니다 (기본은 꺼짐).
- 아이콘 배지 숫자 = 현재 화면에서 가린 개수
- 모든 처리는 브라우저 안에서만 하며 외부로 아무것도 보내지 않습니다.
