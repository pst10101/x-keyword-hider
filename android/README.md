# X 키워드 가리개 (안드로이드)

X 앱 / 브라우저(x.com, twitter.com)에서 키워드가 들어간 게시물을 빨간 **BLOCKED**(Bebas Neue)로 덮고, 덮인 부분은 눌러도 반응하지 않게 막습니다.
시계·알람 앱에서는 알람 이름(라벨)에 키워드가 있으면 그 글자 위를 같은 BLOCKED로 덮습니다.

## 설치
1. `XKeywordHider-debug.apk`를 폰으로 옮겨 실행 → "출처를 알 수 없는 앱 설치" 허용 → 설치.
   PC라면 `adb install -r XKeywordHider-debug.apk` (이 방법은 아래 제한이 잘 안 걸립니다).
2. 업데이트는 지우지 말고 기존 앱 위에 덮어 설치하세요. 같은 디버그 키로 서명돼 있어서 키워드가 그대로 남습니다.

### Play 프로텍트가 막을 때
- "앱이 차단됨"·"안전하지 않은 앱" 창 → '자세히' 또는 '세부정보' → **그래도 설치**.
- '그래도 설치'가 아예 없으면: Play 스토어 → 프로필 → Play 프로텍트 → ⚙ → "Play 프로텍트로 앱 검사"를 잠깐 끄고 설치한 뒤 바로 다시 켜기. 또는 PC에서 `adb install -r`.

## 접근성 켜기 ("앱의 액세스가 거부됨"이 뜰 때)
폰에 직접 받은 APK는 안드로이드 13+ / One UI가 접근성 권한을 **제한된 설정**으로 막습니다. 앱이 스스로 풀 수는 없고, 한 번만 직접 허용하면 됩니다. 앱 첫 화면에 같은 안내와 바로가기 버튼이 있습니다.

1. **접근성에서 한 번 눌러 보기**: 앱의 "접근성 설정 열기" → X 키워드 가리개 → 사용 스위치 → "앱의 액세스가 거부됨" 창을 '확인'으로 닫기. (이걸 해야 2번 메뉴가 생깁니다.)
2. **제한된 설정 허용**: 앱의 "앱 정보 열기" → 오른쪽 위 ⋮ → **제한된 설정 허용** → 지문/PIN 확인.
3. **접근성 서비스 켜기**: 다시 "접근성 설정 열기" → X 키워드 가리개 → 사용 켜기 → 허용. 앱으로 돌아오면 "접근성 서비스 켜짐"이 보입니다.

PC가 있으면 1·2번 대신 이 명령 한 줄이면 됩니다 (앱에 "명령 복사" 버튼 있음):

```
adb shell appops set com.jsw.xkhider ACCESS_RESTRICTED_SETTINGS allow
```

"다른 앱 위에 표시" 권한은 필요 없습니다. 덮개는 접근성 오버레이로 뜹니다.

## 가리는 곳
- **X 앱, 브라우저의 x.com / twitter.com**: 키워드가 걸린 게시물 한 칸 전체. 알림 탭의 알림 항목, X 안에 따로 뜨는 알림 배너·팝업·대화상자의 글도 덮습니다.
- 덮개는 그 앱 위에 떠 있는 다른 창(대화상자·배너, 키보드, 끝까지 내린 알림창)은 가리지 않도록 그 부분을 비켜서 덮습니다.
- **시계·알람 앱** (삼성 시계 `com.sec.android.app.clockpackage`, 구글 시계 `com.google.android.deskclock`, AOSP·샤오미 `com.android.deskclock`, 원플러스·오포 시계): 알람 이름 등 키워드가 들어간 글자만. 글자끼리 겹치면 덮개를 하나로 합쳐 덮습니다. 알람이 울리는 화면의 알람 이름도 덮습니다. (휴대폰 알림창·상단 팝업 알림에 뜨는 X·알람 알림은 시스템 화면이라 덮지 않습니다.)

## 스크롤 따라가기 (1.1.6)
덮개는 스크롤하는 동안 화면 갱신마다(매 프레임) 게시물의 실제 위치를 다시 읽어 따라갑니다. 1.1.5의 앞질러 그리기(예측)는 덮개가 번지거나 튀는 원인이어서 없앴습니다. 빠르게 넘기면 덮개가 게시물보다 살짝 늦을 수는 있지만, 있지 않은 자리로 앞서 가지는 않습니다. 화면 전체를 다시 훑는 일은 별도 스레드에서 따로 해서, 따라가는 속도에 영향을 주지 않습니다. 스크롤이 멈추고 몇 초 지나면 다시 가볍게 쉬어서 배터리를 아낍니다.

- 게시물 하나에 덮개 하나: 덮개는 자기 게시물만 따라가고, 다른 게시물의 덮개로 재사용되지 않습니다.
- 게시물이 사라지거나 내용이 바뀌면 덮개를 다음 화면 갱신을 기다리지 않고 바로 없앱니다.
- 글이 화면 밖으로 나가고 이미지만 남은 게시물도 칸이 보이는 동안 계속 덮습니다. 위로 올릴 때 이미지가 먼저 나타나면 그때 바로 찾아서 덮습니다.
- 게시물 안의 가로 캐러셀에 키워드가 있어도 카드 한 장이 아니라 게시물 전체를 덮습니다.
- 한계: 새 게시물은 화면에 들어온 뒤 찾아서 덮으므로, 아주 빠르게 넘길 때는 덮이기 전까지 아주 잠깐 보일 수 있습니다.

## 쓰는 법
- 앱에서 키워드를 한 줄에 하나씩 적고 **저장**. `/정규식/i`, `//` 메모 가능.
- 덮인 자리는 눌러도 아래 게시물이 열리지 않습니다.
- 덮인 자리 위에서 위·아래로 쓸면 목록이 한 화면씩 넘어갑니다.
- BLOCKED 글자 크기는 덮인 칸 크기에 맞춰 자동으로 맞춰집니다.

## 빌드
`JAVA_HOME=JDK17 gradle :app:assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
(업데이트로 덮어 설치하려면 이전과 같은 `~/.android/debug.keystore`로 빌드해야 합니다.)
