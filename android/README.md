# X 키워드 가리개 (안드로이드)

X 앱 / 브라우저(x.com, twitter.com)에서 키워드가 들어간 게시물을 빨간 **BLOCKED**(Bebas Neue)로 덮고, 덮인 부분은 눌러도 반응하지 않게 막습니다.

## 설치
1. `XKeywordHider-debug.apk`를 폰으로 옮겨 실행 → "출처를 알 수 없는 앱 설치" 허용 → 설치.
   (PC라면 `adb install -r XKeywordHider-debug.apk`.)
   패키지 이름은 `com.jsw.xkhider`입니다. 1.1.2 위에는 그대로 덮어 설치됩니다. 1.1.1(`com.jsw.xkeywordhider`) 위에 업데이트되지 않으므로 새로 설치합니다. 이전 앱은 따로 지울 수 있습니다.
2. 앱 열기 → 키워드 입력(한 줄에 하나, `/정규식/i` 가능) → **저장**.
   맨 위 빨간 BLOCKED 미리보기가 실제로 가려질 때 모습입니다.

## 접근성 서비스 켜기
서비스가 꺼져 있으면 앱 안에 삼성 One UI / 안드로이드 제한된 설정 안내가 나옵니다. 직접 받은 APK의 접근성 권한은 앱이 스스로 풀 수 없습니다.

1. **② 접근성 설정 열기 / 서비스 켜기** → *설치된 앱*(삼성: 설치된 앱 / 다운로드한 앱) → *X 키워드 가리개*. "앱의 액세스가 거부됨"이 뜨면 닫습니다.
2. **① 앱 정보 열기** → 오른쪽 위 ⋮ → **제한된 설정 허용** (지문/PIN). ⋮가 없으면 1번을 먼저 합니다.
3. 다시 접근성 설정에서 서비스를 켭니다.

앱으로 돌아오면 미리보기 아래에 "접근성 서비스 켜짐"이 보이고 안내 상자는 숨겨집니다. PC에서는 **ADB 명령 복사**로 `adb shell appops set com.jsw.xkhider ACCESS_RESTRICTED_SETTINGS allow`를 복사해 실행한 뒤 서비스를 켭니다.

- "다른 앱 위에 표시" 권한은 필요 없습니다. 덮개는 접근성 오버레이로 뜹니다.

X 앱이나 크롬에서 x.com을 열면 걸린 게시물이 BLOCKED로 덮입니다.

## 쓰는 법
- 덮인 자리는 눌러도 아래 게시물이 열리지 않습니다.
- 덮인 자리 위에서 위·아래로 쓸면 목록이 한 화면씩 넘어갑니다 (덮개 때문에 스크롤이 막히지 않게).
- BLOCKED 글자 크기는 덮인 칸 크기에 맞춰 자동으로 맞춰집니다.

## 빌드
`JAVA_HOME=JDK17 gradle :app:assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`
